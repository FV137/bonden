# Bonden

See it through. Leave it simpler.

An experimental fork of [Ponytail](https://github.com/DietrichGebert/ponytail), focused on judgment, completing authorized work, and verifying results.

Read [the core skill](skills/bonden/SKILL.md), [the agent instructions](AGENTS.md), or [installation steps](INSTALL.md#codex).

Validation so far includes the existing automated tests and limited behavioral exercises. Broader reliability and comparative benefits have not been established.
